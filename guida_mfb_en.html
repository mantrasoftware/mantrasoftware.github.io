Mantra for Basket guide

01 · GETTING STARTED

Before you start

What you need, how to film the game, how to install and where your data goes.

About this guide

The buttons are named as they appear with English selected in the program (EN, top right). The screenshots show the program in Italian.

What you need

  • The game video (.mp4, .mov, .mkv, .avi). If the game was recorded in several consecutive files, each file will be a unit.
  • The scoreboard video: a dedicated video is strongly recommended, ideally a tight shot of the scoreboard where clock, score and fouls are easy to read. Two things are essential: the shot must be steady, as fixed as possible, and it must be exactly as long as the game video. With Mantra 360 you get it cropped automatically.
  • The team logos: PNG with a transparent background, ideally square and at least 300 pixels. The program includes six sample logos to try things out.

The perfect recording

The result is decided in the gym: you need two recordings, one locked on the scoreboard and one following the game.

  1. The scoreboard, tight. Frame only the scoreboard: clock, score, fouls and period should fill the picture and be clearly readable. Fixed focus and exposure, no reflections on the digits.

  2. Fixed, as steady as possible. Tripod, no zoom and no movement for the whole game. If the camera stays in the same position, next time you reuse the preset in GEOSCANNER and start straight away.

  3. The game. The second camera follows the play.

  4. Synchronised to the frame. The same moment must fall at the same point in both videos, from start to finish, and the two videos must be the same length:

    • start both recordings together;
    • give a signal both cameras can see, for example a hand clap or a flash;
    • trim the start of both videos exactly on that frame;
    • use the same frame rate (for example 25 or 30 fps) and do not interrupt the recordings.
Automatic with Mantra 360

If you film with a 360° camera, Mantra 360 takes both the game and the scoreboard from the same recording: the two videos are already in sync and the same length. Tips on placing the 360° camera are in the Filming section of the download page.

How to tell if they are out of sync

In AUTOPILOT the score changes before or after the basket you see in the video. If so, check how the start of the two videos was trimmed.

Installation

  1. Run MantraForBasket_Setup.exe. No administrator rights are needed.

    If Windows shows Windows protected your PC, click More info and then Run anyway: the installer has no paid digital signature.

  2. Accept the free licence and, if you like, the desktop shortcut.

  3. Open Mantra for Basket from the Start menu: the HUB opens.

The data folder

Matches, skins, fonts, logos and settings are kept in the Mantra\MantraForBasket folder inside your Documents. If your Documents are synced with OneDrive, the program uses C:\Users\your-name\Mantra instead, so your videos do not end up in the cloud. Updating or uninstalling the program does not touch this folder.

02 · HUB

The HUB and the match

The HUB is the control desk: you choose the match to work on and open every module from there, always on the right files.

Match and unit

A match is a folder with the two teams and the date. Inside it there are one or more units: each unit is one continuous block of recording, for example 01 for the first period, 02 for the second and 05 for overtime. Each unit has its own RAW (videos), DATA (data) and RENDER (finished videos) folders.

  1. In the PROJECT tab type the HOME TEAM and the AWAY TEAM and press CREATE NEW MATCH ENVIRONMENT. For a match you have already created, use Open existing match.

  2. In UNIT (PERIOD) choose an existing unit or type the number of a new one in New n.

  3. Press CONFIRM AND OPEN THE WORKSPACES. ACTIVE WORK ON: appears with match and unit, and the module tabs unlock.

03 · ARCHIVE

Archive and files

The safe way to put videos into the match and to deliver the finished work.

The GUIDE: WHERE TO PUT THE FILES button tells you which folder each thing goes in and opens it for you. The rule is simple: videos go in the unit's RAW folder, logos in the match's _COMMON folder (shared by all units). DATA and RENDER are filled by the modules.

Importing

  1. In the ARCHIVE tab press Import…, or drag the files into the window.

  2. Choose the destination match and unit and the mode:

    • Copy (recommended): the original file stays where it is.
    • Move: the original is removed only after the copy has been verified.
    • Link (videos only, no copy): takes no space, but on Windows it needs Developer Mode or the same disk.

  3. Press IMPORT. If a file already exists you can keep both, skip it or replace it: the old one goes to the match's trash, it is not deleted.

Delivering the work

Export package… gathers into one folder the finished videos, the infographics, the statistics CSV files, the markers and, if you like, the corrected data and a full backup. With Standard name the files get names like Teams_Date_Unit_name.

Nothing gets lost

Move to trash puts the files in the match's _to_delete folder: you can always restore them from there. Do not move files by hand while a module is open.

04 · CAPTURE

GEOSCANNER

Reads the scoreboard frame by frame and writes the match data: clock, score, fouls and period. The setup depends on how the camera frames the scoreboard: you can save it and reuse it as long as the camera stays in the same position.

  1. Load the scoreboard video with 1. LOAD SCOREBOARD VIDEO.

  2. Choose what the scoreboard looks like. In SCOREBOARD TOPOLOGY:

    • TYPE A: always shows MM:SS, no tenths;
    • TYPE B: in the last minute it switches to seconds and tenths (SS.d);
    • TYPE C: always shows tenths (MM:SS.d).

    In TEAM FOULS MODE choose whether fouls are 7-segment digits or LED dots, or whether to ignore them.

  3. Set the foundations with SET FOUNDATIONS:

    • click the 4 corners of the scoreboard (R to start again);
    • press Space to create the ghost: the program runs quickly through the whole video and builds a clean image of the scoreboard. Space pauses, Esc continues;
    • draw a box around the anchor, a part of the scoreboard that never changes, used to follow small movements of the shot;
    • draw a box around the period area.

  4. Map the digits in the OCR MAPPING grid: click a digit (red = to do), draw a box around it and place the points on the segments. When it turns green it is ready. In the box: click to place, drag to move, WASD for 1 pixel, Q/E width, Z/X height, Enter to confirm.

  5. Sample the periods (optional, but needed if the video contains more than one period). The program must see what the period indicator on the scoreboard looks like in each of them:

    • with the VIDEO TIMELINE bar move the video until the scoreboard shows the first period, then sample it with SAMPLE PERIOD, using the crosshair;
    • move the bar again to a point where the scoreboard shows the next period and sample it the same way;
    • repeat for every period in the video.

    This way, during the analysis, the program recognises the change of period by itself.

  6. Start the analysis with START TURBO ANALYSIS. The GEAR decides how many frames to skip between one reading and the next: 1 is maximum precision, 25 maximum speed. You can stop with Q. When the analysis ends you hear a spoken notice.

  7. Press OPEN REFINERY to check the data.

Same framing, zero work

With EXPORT PRESET you save foundations and mapping; next time, if the camera is in the same position and frames the scoreboard the same way, use IMPORT PRESET and you can start the analysis straight away. If the camera has moved, even slightly, redo the foundations.

ENABLE FILTERS, B/W THRESHOLD and CONTRAST only change the preview: they help you see better, they do not change how the numbers are read.

05 · REVIEW

REFINERY

No automatic reading is perfect. REFINERY finds the suspicious rows by itself, shows you the matching frame and gives you the tools to fix them quickly. At the end it saves match_data_correct.json.

The check

  1. With LOAD VIDEO open the game video: every row you select shows its frame. If video and data are not aligned, move the OFFSET (<< and >> = 1 second, < and > = 1 frame).

  2. Use CLEAN to automatically remove spikes in points and fouls and fouls carried over at the start of a quarter, and ⚓ AUTO to find the start of the last minute of every quarter.

  3. Jump from one anomaly to the next with F8 (back: Shift+F8) or with Anomalies only, and fix them.

  4. Press SAVE & CLOSE.

The anomalies

MarkWhat it means
⚡ GLITCHA value that appears and disappears: a typical reading error on one frame.
♻ CARRYFouls left over from the previous quarter at the start of the new one.
WARP · DROPThe clock jumps or the score goes down: check the frame.
⚠ RAPIDPoints rising too fast to be true.
FORMAT? · FIX 00.Clock format to be fixed (MM:SS or SS.D).

The tools

ToolWhat it does
⚓ LAST MINUTEFrom the selected row to the end of the quarter, converts the clock to seconds and tenths (last minute).
🔗 MERGEGives all the selected, adjacent rows the score and fouls of the last one.
🧹 CLEANFinds and fixes spikes, dirty transitions and carried-over fouls.
🪄 AUTO-FILLSpreads the clock evenly between the first and the last selected row (at least 3).
⟲ UNDOUndoes the last change; the number next to it says how many can be undone.
⇄ SWAPSwitches the clock format of the selected rows between MM:SS and SS.D.

Atomic surgery

To correct by hand: select one or more rows, type only the cells to change (empty cells stay as they are) and press Enter or APPLY CHANGES. The cursor jumps to the next cell by itself while you type. Space copies the values from the previous row, Ctrl+Z undoes.

Adjacent rows

MERGE and AUTO-FILL work on rows that follow one another: if Anomalies only or Baskets only is on, some rows are hidden. Turn the filters off before using them.

06 · DIRECT

STUDIO

Sets up the match and prepares the directing in three steps. What you see in the preview is what will come out in the final video, text size included.

  1. Match. Choose the MATCH VIDEO and, if the scoreboard is in a separate recording, the OCR VIDEO. If it does not find the data corrected by REFINERY, STUDIO asks whether to use the raw GEOSCANNER data. LOAD PROJECT reopens a saved job; MANAGE CUTS (CLIPPER) shows the list of clips so you can edit or delete them.

  2. Look and teams. Choose the Graphic (the skin). For each team: name, Fill and Border colour, Black Text if the name reads better dark, and the Logo. The EVENT LOGO is optional: with the MyCity skin you can use one of the cities in assets\logos\Citta.

    With Compact graphics: position you choose the corner where the small score appears during play; Big graphics sets how many seconds the big one stays at the start and end of a clip. Try both versions with Big and Compact under the preview.

  3. Directing. Set the period the video starts from, the period's starting Timer (min) and whether to enable the score effects. Then press LAUNCH DIRECTOR (AUTOPILOT).

When you have finished directing, FINALIZE IN BAKE & EXPORT opens BAKE with the project already loaded.

07 · DIRECT

AUTOPILOT

The control room: you watch the game, choose the plays to keep (the clips) and fix score and graphics where needed. Almost everything is done from the keyboard; ? shows the full legend.

The fastest way

  1. Press H: AUTOPILOT creates a clip around every basket of the game. C does the same for the home team only, O for the away team.

  2. Adjust how much to take before and after each basket: W/E for the start, T/Y for the end, one second at a time.

  3. Go through the clips with the arrows and remove the ones you don't like with D. Merge two nearby clips by selecting them and pressing N.

  4. Exit and save with Q (or Exit & Save, clicked twice).

Clips by hand

R starts recording a clip and R again closes it. With [ and ] you mark the start and end of the part of the game to export. B chooses big or compact graphics for the selected clip; pressed several times it also changes the corner of the compact graphics.

If the program closes

If something goes wrong while directing, AUTOPILOT immediately saves a recovery copy, autopilot_recovery.json, in the data folder. In STUDIO open that file with LOAD PROJECT, choose the videos, press LAUNCH DIRECTOR (AUTOPILOT) and then EDIT EXISTING.

08 · EXPORT

BAKE

Creates the final video: cuts the clips, adds the graphics and uses the computer's graphics card to go as fast as possible.

  1. LOAD PROJECT OR CONFIG: if you come from STUDIO it is already loaded. If the original video has been moved, BAKE asks you where it is.

  2. Check teams, event and SKIN. With PLAY PREVIEW you watch the result before exporting, at the speed you choose.

  3. Choose what to create:

    • MASTER MP4: the finished video, with graphics and audio;
    • EDIT KIT: clean video plus the graphics separately with transparency, to finish in an editing program;
    • GRAPHICS ONLY: just the graphics, in ProRes 4444 with transparency.

  4. Choose the QUALITY PRESET:

    PresetFor
    YOUTUBE (HD)Publishing online, good quality (14 Mbps).
    SOCIAL (SD)Lighter file to share (7 Mbps).
    PRO MASTERMaximum quality in HEVC, for archive or editing (25 Mbps).
    FAST CHECKQuick test at half resolution, to check cuts and graphics.

  5. If you need them, turn on Generate Markers (EDL + CSV): one marker for each basket, to import into editing programs. Then press START PROCESS (TURBO). When the job is done you hear a spoken notice.

The result

The graphics card

Below the options BAKE shows which encoder it is using (NVIDIA, AMD, Intel). If it says No usable GPU: using the CPU, the export still works but is slower: update the graphics card drivers.

09 · GRAPHICS

SKINMAPPER

The skin is the graphics of the score: shapes, colours and the position of names, points, clock, fouls and logos. Every skin has a big and a compact version.

Two modes

  • ✏ DRAW: you add and edit shapes (rectangle, ellipse, polygon, line, text, image), with layers, fills, gradients, outlines and shadows. Shapes can use the team colours: in a game they take the ones chosen in STUDIO.
  • ◎ DATA: you place the elements that change during the game (scores, names, fouls, logos, bonus, clock, period, event logo) and choose their colour, font and size.

Creating a skin

  1. NEW FROM TEMPLATE: choose the style (Classic, Dark, Light), the shape of the big graphics (Full or Thin) and of the compact one (Bar or Square), and give it a name. Otherwise start from a BLANK CANVAS, from a PNG (NEW (LOAD PNG)) or from an SVG drawing (IMPORT SVG, for example from Affinity).

  2. When importing an SVG, choose which colours of the drawing become the team colours; the others stay fixed.

  3. Refine in DRAW, then switch to DATA and place the text. ⇋ MIRROR ALL (A→B) copies the home team's side onto the away side.

  4. Create the compact version with GENERATE COMPACT FROM BIG or SQUARE COMPACT.

  5. Save with SAVE PROJECT. The skin appears straight away in STUDIO and BAKE.

See the real sizes

Turn on Real preview (as BAKE): the skin is drawn as in the final video, over a frame of the latest game or an image chosen with BACKGROUND…. This way the text has the size it will really have.

Keys in DRAW: arrows to move by 1 pixel (Shift for 10), Del deletes, Ctrl+D duplicates, Ctrl while dragging to move without snapping, Ctrl+wheel to zoom. Grid and snap are turned on and off from the bar at the top.

10 · STATISTICS

STATISTICS

Match infographics ready to publish, and the data for Excel.

  1. STATISTICS gathers the data of all the match's units by itself (Reload Global Data to update them).

  2. Choose the theme (Dark, Light or Transparent, to lay over a video), the team colours and logos.

  3. Choose the chart type: Advantage (Momentum), Trend (Lines) or Shot Breakdown (Bars), and the period.

  4. GENERATE GRAPHIC (PNG) creates the image; EXPORT DATA FOR EXCEL (CSV) creates the file with all the match data.

11 · HELP

Common problems

GEOSCANNER misreads some digits

Reopen the OCR MAPPING and check the digit that is wrong: the box must contain the whole digit and the points must sit in the middle of the segments. If the camera moved during the game, redo the foundations. For difficult stretches use a lower GEAR.

Any isolated errors that remain are found and fixed by REFINERY.

In REFINERY the video does not match the data

Move the OFFSET until the frame shows the scoreboard of the selected row. It happens when the scoreboard video and the game video do not start at the same moment.

The clock in the last minute is wrong

Many scoreboards switch from MM:SS to seconds and tenths in the last minute. Use ⚓ AUTO for all quarters, or select the row where the last minute starts and press ⚓ LAST MINUTE.

A module does not open or closes immediately

The HUB shows a message with the RETRY button. The details of the error are in the logs\mantra_hub.log file in the data folder; modules started without a console write to logs\console.log. Attach these files when you report a problem: the HELP tab has the email address and a button that opens the logs folder.

Exporting is slow

Look at the encoder line in BAKE: if it says CPU, the graphics card is not being used. Update the drivers and leave Decode video on the GPU turned on. For a quick check of the cuts use the FAST CHECK preset.

A skin font is missing on this computer

If a skin uses a Microsoft Office font that is not installed (Garamond, Goudy, Eras, Papyrus, Chiller), the program automatically uses a free font that looks similar. To use your own fonts, choose the file in SKINMAPPER: it is copied into the data folder and keeps working even if you move the skin.
