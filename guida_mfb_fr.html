Guide d'utilisation

Guide de Mantra for Basket

De la vidéo du match à une vidéo avec score, temps et fautes en incrustation. Ce guide suit l'ordre dans lequel vous travaillez vraiment : vous préparez le match dans le HUB, lisez le tableau d'affichage, corrigez les données, réalisez les highlights et exportez.

01 · POUR COMMENCER

Avant de commencer

Ce qu'il vous faut, comment filmer le match, comment installer le logiciel et où vont vos données.

À propos de ce guide

Les boutons portent le nom qu'ils ont dans le logiciel avec le français sélectionné (FR, en haut à droite). Les captures montrent le logiciel en italien.

Ce qu'il vous faut

  • La vidéo du match (.mp4, .mov, .mkv, .avi). Si le match a été enregistré en plusieurs fichiers consécutifs, chaque fichier sera une unit.
  • La vidéo du tableau d'affichage : une vidéo dédiée est vivement conseillée, de préférence un plan serré du tableau où le temps, le score et les fautes se lisent bien. Deux choses sont essentielles : la prise doit être stable, la plus fixe possible, et elle doit durer exactement autant que la vidéo du match. Avec Mantra 360, vous l'obtenez recadrée automatiquement.
  • Les logos des équipes : PNG à fond transparent, de préférence carrés et d'au moins 300 pixels. Le logiciel contient six logos d'exemple pour faire des essais.

La captation parfaite

Le résultat se joue dans le gymnase : il faut deux prises de vue, une fixe sur le tableau et une qui suit le match.

  1. Le tableau, en plan serré. Cadrez uniquement le tableau : temps, score, fautes et période doivent remplir l'image et être bien lisibles. Mise au point et exposition fixes, sans reflets sur les chiffres.

  2. Fixe, le plus stable possible. Trépied, pas de zoom ni de mouvement pendant tout le match. Si la caméra reste au même endroit, la fois suivante vous réutilisez le préréglage dans GEOSCANNER et démarrez aussitôt.

  3. Le match. La seconde caméra suit le jeu.

  4. Synchronisées à l'image près. Le même instant doit tomber au même endroit dans les deux vidéos, du début à la fin, et les deux vidéos doivent avoir la même durée :

    • lancez les deux enregistrements ensemble ;
    • faites un signal visible par les deux caméras, par exemple un clap des mains ou un flash ;
    • coupez le début des deux vidéos exactement sur cette image ;
    • utilisez la même fréquence d'images (par exemple 25 ou 30 i/s) et n'interrompez pas les enregistrements.
Automatique avec Mantra 360

Si vous filmez avec une caméra 360°, Mantra 360 tire le match et le tableau du même enregistrement : les deux vidéos sont déjà synchronisées et ont la même durée. Les conseils pour placer la caméra 360° se trouvent dans la section Tournage de la page de téléchargement.

Comment savoir si elles sont désynchronisées

Dans AUTOPILOT, le score change avant ou après le panier que vous voyez dans la vidéo. Dans ce cas, vérifiez la coupe du début des deux vidéos.

Installation

  1. Lancez MantraForBasket_Setup.exe. Aucun droit d'administrateur n'est nécessaire.

    Si Windows affiche Windows a protégé votre ordinateur, cliquez sur Informations complémentaires puis sur Exécuter quand même : l'installateur n'a pas de signature numérique payante.

  2. Acceptez la licence d'utilisation gratuite et, si vous voulez, le raccourci sur le bureau.

  3. Ouvrez Mantra for Basket depuis le menu Démarrer : le HUB s'ouvre.

Le dossier des données

Matchs, skins, polices, logos et réglages se trouvent dans le dossier Mantra\MantraForBasket de vos Documents. Si vos Documents sont synchronisés avec OneDrive, le logiciel utilise à la place C:\Users\votre-nom\Mantra, pour que les vidéos ne partent pas dans le cloud. Mettre à jour ou désinstaller le logiciel ne touche pas ce dossier.

02 · HUB

Le HUB et le match

Le HUB est le poste de commande : vous choisissez le match sur lequel travailler et, de là, vous ouvrez chaque module, toujours sur les bons fichiers.

Match et unit

Un match est un dossier avec les deux équipes et la date. Il contient une ou plusieurs units : chaque unit est un bloc d'enregistrement continu, par exemple 01 pour la première période, 02 pour la deuxième et 05 pour la prolongation. Chaque unit a ses dossiers RAW (vidéos), DATA (données) et RENDER (vidéos finies).

  1. Dans l'onglet PROJET, saisissez l'ÉQUIPE DOMICILE et l'ÉQUIPE EXTÉRIEURE et appuyez sur CRÉER UN NOUVEL ENVIRONNEMENT. Pour un match déjà créé, utilisez Ouvrir un match existant.

  2. Dans UNIT (PÉRIODE), choisissez une unit existante ou saisissez le numéro d'une nouvelle dans Nouvelle n.

  3. Appuyez sur CONFIRMER ET OUVRIR LES ESPACES. TRAVAIL ACTIF SUR : apparaît avec le match et l'unit, et les onglets des modules se débloquent.

03 · ARCHIVES

Archives et fichiers

La façon sûre de mettre les vidéos dans le match et de livrer le travail fini.

Le bouton GUIDE : OÙ METTRE LES FICHIERS vous indique dans quel dossier va chaque chose et l'ouvre pour vous. La règle est simple : les vidéos vont dans le dossier RAW de l'unit, les logos dans le dossier _COMMON du match (partagé par toutes les units). DATA et RENDER sont remplis par les modules.

Importer

  1. Dans l'onglet ARCHIVES, appuyez sur Importer…, ou faites glisser les fichiers dans la fenêtre.

  2. Choisissez le match et l'unit de destination et le mode :

    • Copier (recommandé) : le fichier original reste où il est.
    • Déplacer : l'original n'est retiré qu'après vérification de la copie.
    • Lier (vidéos seulement, sans copie) : n'occupe pas de place, mais sous Windows il faut le Mode développeur ou le même disque.

  3. Appuyez sur IMPORTER. Si un fichier existe déjà, vous pouvez garder les deux, l'ignorer ou le remplacer : l'ancien va dans la corbeille du match, il n'est pas effacé.

Livrer le travail

Exporter le paquet… rassemble dans un dossier les vidéos finies, les infographies, les CSV des statistiques, les marqueurs et, si vous voulez, les données corrigées et une sauvegarde complète. Avec Nom standard, les fichiers prennent des noms du type Équipes_Date_Unit_nom.

Rien ne se perd

Mettre à la corbeille place les fichiers dans le dossier _to_delete du match : vous pouvez toujours les restaurer depuis là. Ne déplacez pas de fichiers à la main pendant qu'un module est ouvert.

04 · ACQUISITION

GEOSCANNER

Lit le tableau image par image et écrit les données du match : temps, score, fautes et période. La préparation dépend de la façon dont la caméra cadre le tableau : vous pouvez l'enregistrer et la réutiliser tant que la caméra reste au même endroit.

  1. Chargez la vidéo du tableau avec 1. CHARGER VIDÉO TABLEAU.

  2. Indiquez comment est fait le tableau. Dans TOPOLOGIE DU TABLEAU :

    • TYPE A : affiche toujours MM:SS, sans dixièmes ;
    • TYPE B : dans la dernière minute, passe aux secondes et dixièmes (SS.d) ;
    • TYPE C : affiche toujours les dixièmes (MM:SS.d).

    Dans MODE FAUTES D'ÉQUIPE, choisissez si les fautes sont des chiffres à 7 segments ou des points LED, ou s'il faut les ignorer.

  3. Posez les fondations avec CALIBRAGE FONDATIONS :

    • cliquez sur les 4 coins du tableau (R pour recommencer) ;
    • appuyez sur Espace pour créer le fantôme : le logiciel parcourt rapidement toute la vidéo et construit une image propre du tableau. Espace met en pause, Échap continue ;
    • encadrez l'ancrage, une partie du tableau qui ne change jamais et qui sert à suivre les petits mouvements de la prise ;
    • encadrez la zone de la période.

  4. Mappez les chiffres dans la grille MAPPAGE OCR : cliquez sur un chiffre (rouge = à faire), encadrez-le et placez les points sur les segments. Quand il est vert, il est prêt. Dans le cadre : clic pour poser, glisser pour déplacer, WASD pour 1 pixel, Q/E largeur, Z/X hauteur, Entrée pour confirmer.

  5. Échantillonnez les périodes (facultatif, mais nécessaire si la vidéo contient plusieurs périodes). Le logiciel doit voir comment l'indication de la période apparaît sur le tableau dans chacune d'elles :

    • avec la barre TIMELINE VIDÉO, déplacez la vidéo jusqu'à ce que le tableau affiche la première période et échantillonnez-la avec ÉCHANTILLON PÉRIODE, en utilisant le viseur ;
    • déplacez de nouveau la barre jusqu'à un moment où le tableau affiche la période suivante et échantillonnez-la de la même façon ;
    • répétez pour chaque période présente dans la vidéo.

    Ainsi, pendant l'analyse, le logiciel reconnaît tout seul le changement de période.

  6. Lancez l'analyse avec DÉMARRER ANALYSE TURBO. La VITESSE décide combien d'images sauter entre deux lectures : 1 est la précision maximale, 25 la vitesse maximale. Vous pouvez arrêter avec Q. À la fin de l'analyse, un message vocal vous prévient.

  7. Appuyez sur OUVRIR REFINERY pour vérifier les données.

Même cadrage, zéro travail

Avec EXPORTER PRÉRÉGLAGE, vous enregistrez fondations et mappage ; la fois suivante, si la caméra est au même endroit et cadre le tableau de la même façon, utilisez IMPORTER PRÉRÉGLAGE et vous pouvez lancer l'analyse aussitôt. Si la caméra a bougé, même un peu, refaites les fondations.

ACTIVER FILTRES, SEUIL N/B et CONTRASTE ne changent que l'aperçu : ils servent à mieux voir, ils ne changent pas la lecture des chiffres.

05 · RÉVISION

REFINERY

Aucune lecture automatique n'est parfaite. REFINERY trouve tout seul les lignes suspectes, vous montre l'image correspondante et vous donne les outils pour les corriger vite. À la fin, il enregistre match_data_correct.json.

La vérification

  1. Avec CHARGER VIDÉO, ouvrez la vidéo du match : chaque ligne sélectionnée affiche son image. Si la vidéo et les données ne sont pas alignées, déplacez l'OFFSET (<< et >> = 1 seconde, < et > = 1 image).

  2. Utilisez NETTOYER pour supprimer automatiquement les pics de points et de fautes et les fautes reportées au début d'un quart-temps, et ⚓ AUTO pour trouver le début de la dernière minute de chaque quart-temps.

  3. Passez d'une anomalie à l'autre avec F8 (en arrière : Maj+F8) ou avec Anomalies seules, et corrigez.

  4. Appuyez sur SAUVER ET FERMER.

Les anomalies

SigneCe que cela veut dire
⚡ GLITCHUne valeur qui apparaît et disparaît : erreur de lecture typique sur une image.
♻ CARRYFautes restées du quart-temps précédent au début du nouveau.
WARP · DROPLe temps fait un saut ou le score baisse : vérifiez l'image.
⚠ RAPIDDes points qui montent trop vite pour être vrais.
FORMAT ? · FIX 00.Format du temps à corriger (MM:SS ou SS.D).

Les outils

OutilCe qu'il fait

Chirurgie atomique

Pour corriger à la main : sélectionnez une ou plusieurs lignes, saisissez seulement les cellules à changer (les cellules vides restent inchangées) et appuyez sur Entrée ou APPLIQUER (ENTRÉE). Le curseur passe tout seul à la cellule suivante pendant la saisie. Espace copie les valeurs de la ligne précédente, Ctrl+Z annule.

Lignes contiguës

FUSIONNER et LISSER TEMPS travaillent sur des lignes qui se suivent : si Anomalies seules ou Paniers seuls est activé, certaines lignes sont masquées. Désactivez les filtres avant de les utiliser.

06 · RÉGIE

STUDIO

Configure le match et prépare la régie en trois étapes. Ce que vous voyez dans l'aperçu est ce qui sortira dans la vidéo finale, taille des textes comprise.

  1. Match. Choisissez la VIDÉO MATCH et, si le tableau est dans une prise séparée, la VIDÉO OCR. S'il ne trouve pas les données corrigées par REFINERY, STUDIO vous demande s'il faut utiliser les données brutes de GEOSCANNER. CHARGER PROJET rouvre un travail enregistré ; GÉRER COUPES (CLIPPER) affiche la liste des clips pour les modifier ou les supprimer.

  2. Look et équipes. Choisissez le Graphisme (la skin). Pour chaque équipe : nom, couleur de Fond et de Bord, Noir si le nom se lit mieux en foncé, et le Logo. Le LOGO ÉVÈNEMENT est facultatif : avec la skin MyCity, vous pouvez utiliser l'une des villes de assets\logos\Citta.

    Avec Graphique réduit : position, vous choisissez le coin où le petit score apparaît pendant le jeu ; Grand graphique indique combien de secondes le grand reste au début et à la fin du clip. Essayez les deux versions avec Grand et Réduit sous l'aperçu.

  3. Régie. Indiquez la période par laquelle commence la vidéo, le Timer (min) de départ de la période et s'il faut activer les effets sur le score. Puis appuyez sur LANCER DIRECTOR.

Une fois la régie terminée, FINALISER DANS BAKE & EXPORT ouvre BAKE avec le projet déjà chargé.

07 · RÉGIE

AUTOPILOT

La salle de régie : vous regardez le match, choisissez les actions à garder (les clips) et corrigez le score et l'habillage si besoin. Presque tout se fait au clavier ; ? affiche la légende complète.

La méthode la plus rapide

  1. Appuyez sur H : AUTOPILOT crée un clip autour de chaque panier du match. C fait la même chose seulement pour l'équipe à domicile, O pour l'équipe extérieure.

  2. Réglez ce qu'il faut garder avant et après chaque panier : W/E pour le début, T/Y pour la fin, une seconde à la fois.

  3. Parcourez les clips avec les flèches et supprimez ceux qui ne vous plaisent pas avec D. Fusionnez deux clips proches en les sélectionnant et en appuyant sur N.

  4. Quittez et enregistrez avec Q (ou Quitter et Sauver, en cliquant deux fois).

Clips à la main

R commence l'enregistrement d'un clip et R à nouveau le ferme. Avec [ et ], vous marquez le début et la fin de la partie du match à exporter. B choisit pour le clip sélectionné le grand ou le petit habillage ; en appuyant plusieurs fois, il change aussi le coin de l'habillage réduit.

Si le logiciel se ferme

Si quelque chose tourne mal pendant la régie, AUTOPILOT enregistre aussitôt une copie de secours, autopilot_recovery.json, dans le dossier des données. Dans STUDIO, ouvrez ce fichier avec CHARGER PROJET, choisissez les vidéos, appuyez sur LANCER DIRECTOR puis sur ÉDITER EXISTENTES.

08 · EXPORT

BAKE

Crée la vidéo finale : coupe les clips, ajoute l'habillage et utilise la carte graphique de l'ordinateur pour aller le plus vite possible.

  1. CHARGER PROJET OU CONFIG : si vous venez de STUDIO, il est déjà chargé. Si la vidéo d'origine a été déplacée, BAKE vous demande où elle se trouve.

  2. Vérifiez les équipes, l'événement et la SKIN. Avec LIRE L'APERÇU, vous regardez le résultat avant d'exporter, à la vitesse que vous choisissez.

  3. Choisissez ce qu'il faut créer :

    • MASTER MP4 : la vidéo finie, avec habillage et son ;
    • KIT DE MONTAGE : vidéo propre plus l'habillage séparé avec transparence, pour finir dans un logiciel de montage ;
    • GRAPHISMES SEULS : seulement l'habillage, en ProRes 4444 avec transparence.

  4. Choisissez le PRÉRÉGLAGE QUALITÉ :

    PréréglagePour quoi
    YOUTUBE (HD)Publication en ligne, bonne qualité (14 Mbit/s).
    SOCIAL (SD)Fichier plus léger à partager (7 Mbit/s).
    PRO MASTERQualité maximale en HEVC, pour l'archive ou le montage (25 Mbit/s).
    FAST CHECKEssai rapide en demi-résolution, pour vérifier coupes et habillage.

  5. Si vous en avez besoin, activez Générer marqueurs (EDL + CSV) : un marqueur pour chaque panier, à importer dans les logiciels de montage. Puis appuyez sur LANCER LE PROCESSUS (TURBO). À la fin, un message vocal vous prévient.

Le résultat

La carte graphique

Sous les options, BAKE indique quel encodeur il utilise (NVIDIA, AMD, Intel). S'il affiche Aucun GPU utilisable : CPU, l'export fonctionne quand même mais il est plus lent : mettez à jour les pilotes de la carte graphique.

09 · GRAPHISMES

SKINMAPPER

La skin est l'habillage du score : formes, couleurs et position des noms, points, temps, fautes et logos. Chaque skin a une version grande et une version réduite.

Deux modes

  • ✏ DESSIN : vous ajoutez et modifiez des formes (rectangle, ellipse, polygone, ligne, texte, image), avec calques, remplissages, dégradés, contours et ombres. Les formes peuvent utiliser les couleurs des équipes : pendant un match, elles prennent celles choisies dans STUDIO.
  • ◎ DONNÉES : vous placez les éléments qui changent pendant le match (scores, noms, fautes, logos, bonus, temps, période, logo de l'événement) et choisissez leur couleur, police et taille.

Créer une skin

  1. NOUVELLE DEPUIS MODÈLE : choisissez le style (Classique, Dark, Light), la forme du grand habillage (Complet ou Thin) et du réduit (Barre ou Carré), et donnez-lui un nom. Sinon, partez d'une TOILE VIDE, d'un PNG (NOUVEAU (CHARGER PNG)) ou d'un dessin SVG (IMPORTER SVG, par exemple depuis Affinity).

  2. En important un SVG, choisissez quelles couleurs du dessin deviennent les couleurs des équipes ; les autres restent fixes.

  3. Peaufinez en DESSIN, puis passez en DONNÉES et placez les textes. ⇋ MIROIR TOUT (A→B) copie la partie de l'équipe à domicile du côté extérieur.

  4. Créez la version réduite avec GÉNÉRER LA RÉDUITE DEPUIS LA GRANDE ou RÉDUITE CARRÉE.

  5. Enregistrez avec ARCHIVER LE PROJET. La skin apparaît aussitôt dans STUDIO et dans BAKE.

Voyez les vraies tailles

Activez Aperçu réel (comme BAKE) : la skin est dessinée comme dans la vidéo finale, sur une image du dernier match ou sur une image choisie avec FOND…. Ainsi, les textes ont la taille qu'ils auront vraiment.

Touches en DESSIN : flèches pour déplacer de 1 pixel (Maj pour 10), Suppr supprime, Ctrl+D duplique, Ctrl en faisant glisser pour déplacer sans aimant, Ctrl+molette pour le zoom. La grille et l'aimant s'activent et se désactivent depuis la barre du haut.

10 · STATISTIQUES

STATISTIQUES

Des infographies du match prêtes à publier, et les données pour Excel.

  1. STATISTIQUES rassemble tout seul les données de toutes les units du match (Recharger les données globales pour les mettre à jour).

  2. Choisissez le thème (Sombre, Clair ou Transparent, à superposer à une vidéo), les couleurs et les logos des équipes.

  3. Choisissez le type de graphique : Avantage (Momentum), Évolution (Lignes) ou Répartition des tirs (Barres), et la période.

  4. GÉNÉRER L'INFOGRAPHIE (PNG) crée l'image ; EXPORTER LES DONNÉES POUR EXCEL (CSV) crée le fichier avec toutes les données du match.

11 · AIDE

Problèmes fréquents

GEOSCANNER lit mal certains chiffres

Rouvrez le MAPPAGE OCR et vérifiez le chiffre qui se trompe : le cadre doit contenir tout le chiffre et les points doivent être au centre des segments. Si la caméra a bougé pendant le match, refaites les fondations. Pour les passages difficiles, utilisez une VITESSE plus basse.

Les erreurs isolées qui restent sont trouvées et corrigées par REFINERY.

Dans REFINERY, la vidéo ne correspond pas aux données

Déplacez l'OFFSET jusqu'à ce que l'image montre le tableau de la ligne sélectionnée. Cela arrive quand la vidéo du tableau et celle du match ne commencent pas au même instant.

Le temps de la dernière minute est faux

Beaucoup de tableaux passent de MM:SS aux secondes et dixièmes dans la dernière minute. Utilisez ⚓ AUTO pour tous les quarts-temps, ou sélectionnez la ligne où commence la dernière minute et appuyez sur ⚓ DERNIÈRE MINUTE.

Un module ne s'ouvre pas ou se ferme aussitôt

Le HUB affiche un message avec le bouton RÉESSAYER. Le détail de l'erreur se trouve dans le journal logs\mantra_hub.log du dossier des données ; les modules lancés sans console écrivent dans logs\console.log. Joignez ces fichiers quand vous signalez un problème : l'onglet AIDE contient l'adresse e-mail et un bouton qui ouvre le dossier des journaux.

L'export est lent

Regardez la ligne de l'encodeur dans BAKE : s'il indique CPU, la carte graphique n'est pas utilisée. Mettez à jour les pilotes et laissez activé Décoder la vidéo avec le GPU. Pour un essai rapide des coupes, utilisez le préréglage FAST CHECK.

Une police de la skin manque sur cet ordinateur

Si une skin utilise une police de Microsoft Office qui n'est pas installée (Garamond, Goudy, Eras, Papyrus, Chiller), le logiciel utilise automatiquement une police libre d'aspect proche. Pour utiliser vos propres polices, choisissez le fichier dans SKINMAPPER : il est copié dans le dossier des données et continue de fonctionner même si vous déplacez la skin.
